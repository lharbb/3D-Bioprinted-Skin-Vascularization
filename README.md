# 3D-Bioprinted Skin Vascularization

## Project Description
This project is a literature review investigating vascularization strategies used in 3D-bioprinted human skin constructs and their reported outcomes.

## Research Focus
The review focuses on vascular network formation, endothelial cells, perfusion, graft survival, and the challenges of vascularizing bioprinted skin.

## Data Sources
The project uses published scientific literature identified through PubMed, Scopus, and IEEE Xplore.

## Analysis
Relevant studies will be screened, critically evaluated, and compared to identify current approaches, limitations, and research gaps.
